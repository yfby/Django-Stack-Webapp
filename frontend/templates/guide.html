ACTIVITY A · LECTURE 1

Print queue behaviour

backend/dsa/queue.py

The starter runnable picks the newest waiting print job. Make it a FIFO queue so the earliest arrival leaves first.

  1. Keep ServiceQueue and its public method names.
  2. Fix dequeue() and peek(). Use efficient end operations.
  3. Keep to_list() in arrival order for saving and reloading.
  4. Create print jobs A, B and C. Add them in that order. Start A, B, C, refreshing between requests.
  5. Run CHECK_QUEUE.bat.

ACTIVITY B · LECTURE 2

Singly linked storage

backend/dsa/singly_linked_list.py

The starter's methods use a Python list. Replace that backing storage with real Node objects and next references.

  1. Initialize head, tail and a cached _size.
  2. Implement the existing insertion, search, get and removal methods.
  3. Handle an empty list, one node, duplicates and invalid indices.
  4. Follow next until None for traversal.
  5. Run CHECK_LINKED_LIST.bat and inspect the real links on the Production flow page.
